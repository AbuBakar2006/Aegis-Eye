================================================================================
                         FILE FUNCTION & RESPONSIBILITY MATRIX                  
================================================================================

1. AegisEye/main.py
   Main system entry point. Handles self-healing startup dependency checks 
   (_ensure_dependencies), launches the dark-themed video selector GUI 
   (Run, Browse, 📷 Add Location), and spawns parallel threads for camera feeds.

2. AegisEye/config.py
   Central system configuration module. Dynamically sets absolute paths for 
   PROJECT_ROOT, Models/, Test_Videos/, Storage/, Twilio SMS credentials, and 
   parses camera_locations.json metadata.

3. AegisEye/detect_cameras.py
   Interactive camera setup tool. Scans hardware webcams (0..3) & phone streams 
   (IP Webcam / DroidCam), tests live stream connections, prompts for street 
   address & GPS coordinates, and saves records into camera_locations.json.

4. AegisEye/export_onnx.py
   One-time model conversion utility. Exports PyTorch (.pt) models to ONNX 
   format (.onnx) for 2–4x faster CPU inference.

5. AegisEye/core/detector.py
   Core 3-thread pipeline (Reader, Infer, Display). Handles Model A accident 
   detection at native 640 quality every 15 frames, Model B vehicle 
   classification, 3-second broadcast delay, and foreground window focus.

6. AegisEye/core/buffer.py
   Thread-safe circular frame buffer (FrameBuffer) using collections.deque. 
   Continuously retains the last 10 seconds of raw video frames prior to a crash.

7. AegisEye/core/severity.py
   Optical flow severity scoring engine (compute_severity). Uses OpenCV 
   Farneback optical flow to measure motion vectors and calculate accident 
   severity (0.0 to 1.0).

8. AegisEye/core/blackbox.py
   Blackbox clip recorder (save_blackbox_clip). Takes the 10-second pre-crash 
   buffer and encodes it into a compressed H.264 MP4 file saved in Storage/BlackBox-Clips/.

9. AegisEye/services/alert.py
   Emergency SMS alert service (send_alert). Integrates Twilio API to dispatch 
   immediate SMS alerts with camera name, street location, vehicles involved, 
   timestamp, and a Google Maps navigation link.

10. AegisEye/services/report.py
    Automated insurance PDF generator (generate_report). Uses fpdf2 to construct 
    formal PDF reports with severity score breakdowns, camera GPS, and clickable 
    clip links saved in Storage/Reports/.

11. AegisEye/api/server.py
    FastAPI backend REST API server (app). Exposes endpoints (/api/incidents, 
    /api/incidents/{id}/clip, /api/incidents/{id}/report) for the Web Dashboard interface.

12. camera_locations.json
    External JSON database containing metadata for all camera locations (IDs, 
    names, street addresses, stream URLs, GPS coordinates, Google Maps links).

13. settings.json
    Stores user-configured local runtime overrides (frame_skip, display_delay).

14. requirements.txt
    Master Python package dependency list specifying exact versions for all libraries.

15. .gitignore
    Git exclusion rules for large binary models, test videos, virtual environments, 
    and generated outputs.

16. CHANGELOG.md
    Chronological development log documenting all feature additions, bug fixes, 
    and structural changes.

17. README.md
    Primary setup and operational guide for the repository.
